설정

고급 설정

시스템 프롬프트, Temperature와 함께 provider 라우팅, 폴백 모델, 응답 파라미터를 세밀하게 제어합니다. 비워두면 OpenRouter 기본값이 사용됩니다.

일반 Provider 라우팅 모델 폴백 요청 파라미터 응답 형식 데이터 관리

일반

시스템 프롬프트와 응답의 창의성(Temperature)을 설정합니다.

무료 모델 전체에 test API 호출을 해본 결과 오류 응답을 반환한 모델입니다. 기본적으로 모델 선택 목록에서 제외됩니다. 켜면 다시 표시됩니다.

사이드바 모델 선택 목록에 표시할 모델의 가격 범위를 정합니다. "1달러 미만만 표시"는 100만 토큰당 프롬프트 가격이 $1 미만인 모델(무료 포함)만 보여줍니다.

사이드바 모델 선택, 폴백 모델 검색, Provider 라우팅의 대상 모델 목록에 100만 토큰당 가격을 함께 보여줍니다. 기본값은 미표시입니다.

대화 전체에 적용될 모델의 역할과 지침을 정의합니다.

0.7

값이 낮을수록 일관되고 예측 가능한 답변을, 높을수록 창의적이고 다양한 답변을 생성합니다 (기본값 0.7).

Provider 라우팅

동일한 모델을 여러 회사(provider)가 서빙할 때, 어떤 곳을 우선하고 어떤 곳을 제외할지 정합니다.

모델을 선택하면 해당 모델을 지원하는 provider만 아래 목록에 표시됩니다.

선택한 순서대로 provider를 시도합니다. 비워두면 OpenRouter가 자동으로 최적 provider를 고릅니다. 목록에서 골라 추가하세요.

우선순위를 직접 정하지 않을 때, 후보 provider를 어떤 기준으로 정렬해서 시도할지 선택합니다.

우선순위의 provider가 실패하면 다른 provider로 자동 전환합니다. 끄면 지정한 provider에서만 시도합니다.

temperature, top_p 등 이 화면에서 지정한 파라미터를 지원하지 않는 provider는 후보에서 제외합니다.

요청/응답 데이터를 학습 등에 활용할 수 있는 provider를 허용할지 결정합니다. 민감한 대화라면 "거부"를 권장합니다.

선택한 provider는 라우팅 후보에서 완전히 제외됩니다.

선택한 정밀도의 모델만 사용합니다. FP32에 가까울수록 정확하지만 느리고 비쌀 수 있고, INT4에 가까울수록 빠르고 저렴하지만 품질이 낮아질 수 있습니다. 아무것도 선택하지 않으면 전체 허용됩니다.

모델 폴백

기본으로 선택한 모델이 응답할 수 없을 때(장애, 과부하 등) 순서대로 시도할 대체 모델을 지정합니다.

이름이나 ID로 검색한 뒤 클릭하면 목록에 추가됩니다. 추가된 순서대로 시도합니다.

요청 파라미터

모델의 응답 스타일과 길이를 제어하는 세부 파라미터입니다. 각 항목의 스위치를 켜야 요청에 포함됩니다.

응답의 최대 토큰 수를 제한합니다. 비워두면 모델 기본값 사용.

동일한 seed와 입력이면 재현성이 높아집니다 (지원 모델에 한함).

기본값

확률 상위 P%의 토큰만 후보로 사용합니다. 낮을수록 보수적·일관적, 높을수록 다양한 답변 (기본값 1).

기본값

확률 상위 K개의 토큰만 후보로 사용합니다 (일부 모델만 지원, 기본값 0=제한 없음).

기본값

이미 등장한 단어의 반복 사용을 억제합니다. 값이 클수록 같은 단어 반복이 줄어듭니다 (기본값 0).

기본값

새로운 주제·단어 사용을 장려합니다. 값이 클수록 더 다양한 주제를 시도합니다 (기본값 0).

기본값

반복되는 문구 자체에 불이익을 줍니다. 1보다 크면 반복 억제, 작으면 완화됩니다 (기본값 1).

응답 형식 및 컨텍스트

모델이 순수 JSON 객체 형태로만 응답하도록 강제합니다 (response_format: json_object). 지원 모델에서만 동작합니다.

입력이 모델의 컨텍스트 길이를 초과할 때, 중간 부분을 압축해 자동으로 맞춰줍니다.
